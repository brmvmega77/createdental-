# Правила разработки

По образцу CBDO Panel: изменения сначала выполняются и проверяются локально; законченные изменения сохраняются отдельными понятными Git-коммитами; в коммит входят только нужные файлы. GitHub служит источником для сервера, а развёртывание и проверка сервера выполняются после публикации. Исходники на сервере напрямую не редактируются.

Этот проект пока представлен отдельной локальной папкой без Git-репозитория и настроенного удалённого адреса. Публикация будет возможна после их подключения.
