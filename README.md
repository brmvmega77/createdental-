# Create Dental

Портал для клиник, главного техника и исполнителей. Нужен Node.js 20 или новее.

## Запуск

```sh
SUPPORT_TOKEN_FILE=.data/support-token npm start
```

Локальный адрес: http://127.0.0.1:4173/. Проверка синтаксиса: `npm run check`.

На первом экране одна форма входа для всех. Клиника регистрируется по ссылке под кнопкой «Войти»: нужны название, email и пароль (от 10 символов). Техники входят по рабочему email и паролю, которые задаёт главный техник в разделе «Команда». Главный техник входит по выданным ему логину и паролю; общий ключ оператора чата для входа в портал не подходит. Ссылка «Забыли пароль?» показывает порядок обращения к главному технику; автоматическая отправка письма пока не настроена. Отдельные сеансы хранятся в памяти сервера и сбрасываются при его перезапуске.

Адреса страниц используют пути: `/login`, `/register`, `/forgot-password`, `/clinic`, `/clinic/orders`, `/clinic/orders/{id}`, `/technician`, `/technician/team`, `/technician/analytics`, `/worker`, `/worker/orders`. Старые адреса с `?role=` автоматически заменяются на новые.

Данные заказов, клиентов, сотрудников и этапов сохраняются в `.data/portal.json`; учётные записи с хешами паролей — в `.data/accounts.json`. Исходные демонстрационные клиники, техники и заказы удаляются при загрузке данных; добавленные вручную записи сохраняются. Клиника видит только свои заказы, техник — только назначенные ему. Отключённый или уволенный техник теряет доступ к кабинету.

Для сброса всех пользователей и создания одного главного техника запустите `node reset-users.mjs ИМЯ`, передав пароль через стандартный ввод. Эта команда удаляет учётные записи, карточки клиник и сотрудников, а также назначения исполнителей; сами заказы сохраняются. После сброса перезапустите сервер, чтобы закрыть старые сеансы.

Главный техник может добавлять и редактировать техников, назначать заказы и принимать работы после проверки качества. У новых техников обязательны email и пароль. Клиники, добавленные главным техником, могут зарегистрироваться по тому же email и получить доступ к своей карточке.

Аналитика показывает стоимость завершённых заказов, число заказов и распределение по клиникам и техникам. Это не подтверждённая оплата и не прибыль: учёт платежей и себестоимости не реализован. Файлы заказов пока не загружаются на сервер.

## Публикация

`docker compose up -d --build` запускает проект отдельно на порту 4173. Для регистрации и входа через интернет нужен HTTPS: не передавайте пароли через прямой адрес сервера по HTTP. Файл `.data/support-token` должен быть доступен пользователю контейнера (UID 1000). Панель оператора чата находится на `/support.html` и использует тот же ключ, если отдельный `SUPPORT_TOKEN` не задан.
