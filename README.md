# Create Dental — клиентский портал

Статический фронтенд на HTML, CSS и JavaScript с локальными демонстрационными данными. Визуальный референс сохранён в `public/assets/design-reference.png`.

## Запуск

Node.js 20 или новее:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Проверка синтаксиса: `npm run check`.

На сервере проект запускается отдельно от других приложений через `docker compose up -d --build` из каталога `/opt/create-dental`. Для работающего чата перед запуском нужен файл `.data/support-token`, доступный пользователю контейнера (UID 1000). Контейнер открывает порт 4173; прямой IP-адрес использует HTTP, поэтому реальные данные пациентов без HTTPS и авторизации вводить нельзя.

Интерфейс включает главную, пять шагов нового заказа, список и карточку заказа, файлы, сообщения, справочник и профиль клиники. Заказы пока демонстрационные и остаются только в текущей вкладке. Сообщения чата сохраняются на локальном сервере в `.data/chat.json` и обновляются в браузере каждые три секунды.

## Кабинет главного техника

Откройте `http://127.0.0.1:4173/?role=technician` или перейдите из кабинета клиники кнопкой в верхней панели. Здесь можно назначать техников, переводить заказы между этапами, принимать готовые работы и возвращать их на доработку. В разделе «Клиенты» можно искать, добавлять, редактировать и удалять клиники из справочника. Изменения сохраняются локально в браузере; удаление из справочника сохраняет историю заказов и аналитики.

Разделы кабинета техника можно открыть напрямую параметром `page`, например `?role=technician&page=clients` или `?role=technician&page=analytics`.

В разделе «Команда» главный техник ведёт список сотрудников: добавляет и редактирует данные, отключает доступ, включает обратно или увольняет сотрудника. При увольнении незавершённые работы возвращаются в очередь назначения. Отдельный кабинет исполнителя доступен по `?role=worker`: в нём видны только назначенные выбранному технику заказы, детали работ, этапы и профиль. Исполнитель переводит работу вплоть до контроля качества; принять результат может главный техник. Состав команды и этапы в этой версии хранятся в `localStorage` браузера, поэтому отключение не является серверной блокировкой учётной записи. Для реальной работы потребуются авторизация и серверное хранение.

На вкладке «Аналитика» есть выручка, число заказов, средний чек, график по месяцам и результаты по клиникам и техникам. Доступны выбор месяца и техника, сортировка клиентов по выручке или количеству заказов. Все финансовые данные пока демонстрационные: для реальных результатов нужно подключить заказы и оплаты лаборатории. Показана выручка, а не прибыль — себестоимость работ в проекте отсутствует.

## Чат поддержки

Клиент пишет из раздела «Сообщения». Оператор отвечает на `http://127.0.0.1:4173/support.html`. Для панели оператора задайте ключ при запуске:

```sh
SUPPORT_TOKEN='длинный-случайный-ключ' npm start
```

Ключ можно хранить в отдельном файле и передать путь через `SUPPORT_TOKEN_FILE`. Без ключа отправка сообщений клиентом работает, а панель оператора закрыта. Перед публикацией на сервере необходимы учётные записи, HTTPS и правила хранения персональных данных.

Сумма заказа сейчас демонстрационная: она рассчитывается по временным ставкам в `app.js`. Для реальных заказов нужен согласованный прайс-лист.
