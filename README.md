# Create Dental — клиентский портал

Статический фронтенд на HTML, CSS и JavaScript с локальными демонстрационными данными. Визуальный референс сохранён в `public/assets/design-reference.png`.

## Запуск

Node.js 20 или новее:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Проверка синтаксиса: `npm run check`.

Интерфейс включает главную, пять шагов нового заказа, список и карточку заказа, файлы, сообщения, справочник и профиль клиники. Данные не отправляются на сервер; созданные заказы и сообщения остаются только в текущей вкладке до перезагрузки.

Правила работы описаны в [PROJECT_WORKFLOW.md](PROJECT_WORKFLOW.md). Снимки страниц лежат в `artifacts/preview/`.
