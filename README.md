# Create Dental — клиентский портал

Портал Create Dental на HTML, CSS, JavaScript и Node.js. Визуальный референс сохранён в `public/assets/design-reference.png`.

## Запуск

Node.js 20 или новее:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Проверка синтаксиса: `npm run check`.

На сервере проект запускается отдельно от других приложений через `docker compose up -d --build` из каталога `/opt/create-dental`. Перед запуском нужен файл `.data/support-token`, доступный пользователю контейнера (UID 1000), либо переменная `PORTAL_TOKEN` для входа в портал и `SUPPORT_TOKEN` для панели чата. Контейнер открывает порт 4173. Прямой IP-адрес использует HTTP: до настройки HTTPS и отдельных учётных записей реальные данные пациентов вводить нельзя.

Интерфейс включает главную, пять шагов нового заказа, список и карточку заказа, файлы, сообщения, справочник и профиль клиники. Заказы, клиенты, сотрудники и этапы работ сохраняются в `.data/portal.json` и загружаются при открытии страницы. Сообщения чата сохраняются в `.data/chat.json` и обновляются в браузере каждые три секунды. Ключ входа общий для всех ролей; отключение сотрудника скрывает его кабинет в интерфейсе, но отдельные учётные записи пока не реализованы. При одновременном редактировании одинаковых разделов с разных устройств последнее сохранение может перезаписать предыдущее.

## Кабинет главного техника

Откройте `http://127.0.0.1:4173/?role=technician` или перейдите из кабинета клиники кнопкой в верхней панели. Здесь можно назначать техников, переводить заказы между этапами, принимать готовые работы и возвращать их на доработку. В разделе «Клиенты» можно искать, добавлять, редактировать и удалять клиники из справочника. Изменения сохраняются на сервере; удаление из справочника сохраняет историю заказов.

Разделы кабинета техника можно открыть напрямую параметром `page`, например `?role=technician&page=clients` или `?role=technician&page=analytics`.

В разделе «Команда» главный техник ведёт список сотрудников: добавляет и редактирует данные, отключает, включает обратно или увольняет сотрудника. При увольнении незавершённые работы возвращаются в очередь назначения. Отдельный кабинет исполнителя доступен по `?role=worker`: в нём видны только назначенные выбранному технику заказы, детали работ, этапы и профиль. Исполнитель переводит работу вплоть до контроля качества; принять результат может главный техник.

На вкладке «Аналитика» есть стоимость завершённых заказов, число заказов, средний чек, график по месяцам и результаты по клиникам и техникам. Доступны выбор месяца и техника, сортировка клиентов по стоимости или количеству заказов. Суммы берутся из сохранённых заказов после приёмки качества. Это не подтверждённая выручка по оплатам и не прибыль: оплат и себестоимости в проекте пока нет. Начальные заказы имеют даты 2024 года, поэтому за текущий год график будет пуст до создания и завершения новых заказов.

## Чат поддержки

Клиент пишет из раздела «Сообщения». Оператор отвечает на `http://127.0.0.1:4173/support.html`. Для панели оператора задайте ключ при запуске:

```sh
SUPPORT_TOKEN='длинный-случайный-ключ' npm start
```

Ключ можно хранить в отдельном файле и передать путь через `SUPPORT_TOKEN_FILE`. Без ключа отправка сообщений клиентом работает, а панель оператора закрыта. Перед публикацией на сервере необходимы учётные записи, HTTPS и правила хранения персональных данных.

Сумма заказа сейчас демонстрационная: она рассчитывается по временным ставкам в `app.js`. Для реальных заказов нужен согласованный прайс-лист.
