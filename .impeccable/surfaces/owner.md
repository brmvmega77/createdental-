# Owner cabinet
Mode: Operate. Audience: laboratory founder/CEO. Extend the existing Create Dental visual system; no new visual identity. Separate owner login confirmed by user.

## Direction contract
THESIS: Start with decisions requiring attention, then provide traceable financial and operational measures. Do not invent accounting figures from order prices.
OWN-WORLD: Use the actual shared styles.css, orders-overrides.css, auth-layout.css, mobile-cabinets.css, neutral-palette.css and clinic-mobile-ui.css. Owner-specific CSS controls content layout only. Font, buttons, panels, forms, logo, footer and navigation inherit existing cabinet classes.
STORY: The owner sees a dated summary, opens a relevant section, inspects underlying orders and fills missing cost data where necessary.
FIRST VIEWPORT: Desktop sidebar; title and date range; grouped financial readings; actionable exceptions alongside the current production queue. Mobile and tablet switch at the shared 900px boundary to the existing five-item bottom navigation and sidebar drawer. The top bar is sticky. Date selection opens the common mobile sheet; the duplicate section selector is removed. Desktop supports the existing collapsed sidebar. Signature interaction: each financial aggregate explains its basis and opens its actual order cohort.
FORM: Established cabinet extension with an owner-specific navigation and data hierarchy; pinned incumbent system; no visual-world replacement.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
