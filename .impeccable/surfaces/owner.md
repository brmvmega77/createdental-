# Owner cabinet
Mode: Operate. Audience: laboratory founder/CEO. Extend the existing Create Dental visual system; no new visual identity. Separate owner login confirmed by user.

## Direction contract
THESIS: Start with decisions requiring attention, then provide traceable financial and operational measures. Do not invent accounting figures from order prices.
OWN-WORLD: Existing light Create Dental palette, graphite text, white panels, restrained gray borders, established logo, familiar sans-serif, 12-16px panel radii.
STORY: The owner sees a dated summary, opens a relevant section, inspects underlying orders and fills missing cost data where necessary.
FIRST VIEWPORT: Desktop sidebar; title and date range; grouped financial readings; actionable exceptions alongside the current production queue. Mobile uses a section selector plus bottom navigation with no horizontal tabs. Signature interaction: each financial aggregate explains its basis and opens its actual order cohort.
FORM: Established cabinet extension with an owner-specific navigation and data hierarchy; pinned incumbent system; no visual-world replacement.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
